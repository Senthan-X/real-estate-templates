# Senthan & Co — Real Estate Templates

A collection of distinct, multilingual real-estate website templates crafted by Senthan & Co.

## Production order

1. Aurelia Estates — Luxury Real Estate Agency
2. Nestgrid — Modern Property Marketplace
3. Urban Apartment & Rental Portal
4. Property Developer & New Projects
5. Independent Real Estate Agent Portfolio
6. Villa & Vacation Property Template
7. Commercial Real Estate Agency

## Template standard

Each deployment build is a zero-dependency, self-contained HTML file with Base64-embedded WebP imagery, light and dark themes, seven-language i18n including Arabic RTL, responsive layouts, scroll-triggered motion, defensive local storage, a signature interaction, and a Back-to-Top Button.
